Bằng chứng của Yêu cầu 3, báo cáo tổng hợp và các biểu mẫu đã điền sẽ được bổ sung khi thực hiện. Lịch sử commit ghi nhận các phiên bản tệp từ lúc kho Git được khởi tạo; thời gian trong prompt log ghi nhận các lần trao đổi với AI và có thể khác thời gian commit.

Để xuất lịch sử cho giảng viên:

```bash
git log --graph --all --date=iso-strict --format=fuller --stat > Git_Commit_Log.txt
```
